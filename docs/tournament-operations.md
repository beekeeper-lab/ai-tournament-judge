# Tournament Operations

The default format is constrained-random single elimination. Freeze the entrant list, bye policy, affiliation groups, prior finalists, and random seed before publishing the bracket.

For 20 teams, the bracket has 32 slots: eight teams enter four preliminary matches and twelve receive byes. `performance-qualified` byes use consolidated scores; tied cutoff positions are resolved with recorded randomness. Alternative policies must be selected before the draw.

Each matchup uses two independent order-reversed comparisons. A confirmed winner requires agreement outside the close-call band. Human officials resolve remaining ties and all rules questions. Never alter the bracket to create a preferred ceremony outcome.

If an entrant withdraws, apply the event's published withdrawal rule. Do not silently redraw after matchups start. Record every correction, approval, and advancement.
